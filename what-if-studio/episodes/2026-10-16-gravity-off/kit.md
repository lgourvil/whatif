# What If #2026-10-16 — What if gravity switched off for 10 seconds?

**Thème :** physique absurde / planète · **Échelle de temps :** décomposée, au ralenti (×5) — « 0.0s » → « 0.4s » → « 1.1s » → « 2.5s » → « 4.8s » → « 7.2s » → « 9.9s » → « 10.0s » → « 10.1s » · **Durée :** 72 s · 9:16 · 1080×1920 · 30 fps
**Personnage récurrent :** *Pip* (compagnon original : corps rond, visière noire, longue écharpe, antenne lumineuse), ici version corail.

## Hook (0–2 s)
Place dans un parc, matin doré, vue subjective, vos mains dans le cadre, Pip vous salue. Texte lisible dès la frame 0, sans fondu : **« 0.0s — POV: gravity just switched off »**. Les premières herbes se détachent du sol.

## Structure (72 s)
1. **Hook (0–8 s)** : calme trompeur, un bout d'herbe flotte déjà.
2. **Escalade (8–28 s)** : vos pieds quittent le sol, l'étang se transforme en bulles d'eau qui montent, bancs, arbres, voitures, maisons déracinés. Pip tourbillonne.
3. **Traversée (20–44 s)** : plongée blanche dans les nuages, puis au-dessus : ciel violet, étoiles, le monde rapetisse.
4. **Retournement (44–50 s)** : « 9.9s — it's coming back ». Dolly zoom vertigineux, silence sonore (tout s'éteint sauf le cœur).
5. **Chute (50–54 s)** : « 10.0s — HOLD ON ». Gravité de retour, chute libre, sol qui se rapproche, impact blanc.
6. **Boucle (54–72 s)** : le parc est intact, personne n'a rien remarqué. Même plaza, même cadre qu'à la frame 0.

## Conception sonore
- 1 : nappe lente (Cmaj7 → Am7 → Fmaj7 → G), vent léger, cœur ~62 bpm, respiration calme. SFX : tic discret à chaque horodatage.
- 2 : carillons de cristal dans la nappe, le vent monte, whoosh doux aux changements de mouvement. Exclamation du POV : « uh… whoa ? ».
- 3 : whoosh dans les nuages (deux passes, entrée et sortie blanche), la nappe s'ouvre (filtre).
- 4 : sifflement d'air qui s'amincit (bruit haut), drone grave qui monte avec la tension, cœur ~100 bpm.
- 5 : « swell » (riser) puis **silence quasi total** (tout baisse sauf le cœur) juste avant le retour. Mots-clés CapCut/TikTok : « riser », « silence before drop », « heartbeat ».

- 7 : crash + grondement, tout retombe.
- 8 : retour au calme, nappe douce, une dernière respiration. Crossfades partout, aucune coupure sèche ; boucle loop-safe (fondus 50 ms / 0,4 s).
